Chat Translator — настройки

Перевод

Если в ответе нет русских букв, он сначала переводится в кириллицу. Цифры 4 = ч, 6 = ш внутри слов тоже понимаются.

Сервис перевода

Бесплатный ключ: deepl.com → API → план Developer (разово 1 млн символов, без карты). Ключ, который кончается на :fx, — бесплатный.

Google Cloud Console → включить «Cloud Translation API» → Credentials → API key.

Ключ: console.anthropic.com → API Keys. Для экономии можно указать модель claude-haiku-5-5.

Ключи хранятся только в этом браузере (chrome.storage.local) и отправляются только в выбранный сервис перевода.
