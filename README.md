# Frog Chat Translator

Расширение для Chrome (Manifest V3). Переводит входящие сообщения веб-чата на русский прямо под оригиналом и помогает ответить: пишешь по-русски, перевод вставляется в поле чата. Кнопку «Отправить» на сайте человек нажимает сам.

Готовые адаптеры: Chaturbate, WhatsApp Web, Telegram Web, Discord. На любом другом сайте: значок расширения → «Включить перевод на этом сайте» → 🎯 на панели → клик по сообщению собеседника. Ответ можно писать транслитом (privet, 4to, moje6i). Дальше: Instagram, Skype, Telegram Web.

## Установка в Chrome

1. Скачай папку `extension` (или весь репозиторий).
2. Открой `chrome://extensions`, включи «Режим разработчика» (справа сверху).
3. «Загрузить распакованное расширение» → выбери папку `extension`.
4. Нажми на значок расширения → «Настройки», выбери сервис перевода и вставь ключ → «Проверить перевод».

После обновления файлов: на `chrome://extensions` нажми ↻ у расширения и обнови вкладку с чатом (F5).

## Сервисы перевода

| Сервис | Где взять ключ | Заметки |
|---|---|---|
| DeepL (по умолчанию) | deepl.com → API → план Developer (бесплатный, без карты) | Разово 1 млн символов бесплатно, дальше платно. Бесплатный ключ кончается на `:fx`. |
| Google Cloud Translation | Google Cloud Console → Cloud Translation API → API key | Платно после бесплатного лимита. |
| Claude | console.anthropic.com → API Keys | Модель меняется в настройках (по умолчанию `claude-opus-5-5`, дешевле `claude-haiku-5-5`). |
| Проверка | ключ не нужен | Не переводит, только добавляет метку `[RU]`. Нужен, чтобы проверить, что расширение находит сообщения и поле ввода. |

Ключи хранятся только в браузере (`chrome.storage.local`) и уходят только в выбранный сервис. В коде и в репозитории ключей нет.

## Как пользоваться

- Новые сообщения чата получают перевод под оригиналом (при открытии страницы переводятся последние 30).
- Сообщения на русском, эмодзи и системные уведомления не переводятся.
- Внизу слева панель «Переводчик»: пишешь ответ по-русски, жмёшь «Перевести и вставить» (или Ctrl+Enter). Язык ответа: «авто» = язык последнего собеседника, или выбери вручную.
- Кнопка ⏻ на панели или галочка во всплывающем меню включают и выключают перевод.
- Одинаковые сообщения берутся из кэша и не тратят лимит. Кэш очищается в настройках.

## Если на сайте перевод не появляется

Сайты меняют вёрстку. Селекторы каждого сайта собраны в одном месте, в объекте `SELECTORS`: [`chaturbate.js`](extension/content/adapters/chaturbate.js), [`whatsapp.js`](extension/content/adapters/whatsapp.js).

1. На сайте нажми F12 → стрелка «выбрать элемент» → кликни по сообщению в чате.
2. Посмотри `class` или `data-testid` у блока сообщения, текста, поля ввода.
3. Добавь их первыми строками в нужный список `SELECTORS` и перезагрузи расширение.

Если поле ввода не нашлось, панель всё равно вставит текст в поле, по которому ты кликнула последним.

## Устройство

```
extension/
  manifest.json
  background/            фон: запросы к сервисам перевода, кэш, настройки
    service-worker.js
    providers.js         DeepL, Google, Claude, Проверка
    cache.js
    settings.js
  content/               скрипты на странице чата
    main.js              ядро: следит за чатом, переводит, вставляет ответ
    ui.js / ui.css       панель ответа и вид перевода
    adapters/
      chaturbate.js      адаптер Chaturbate (селекторы)
      whatsapp.js        адаптер WhatsApp Web
      registry.js        выбор адаптера по сайту
  popup/                 меню по клику на значок
  options/               страница настроек
test/
  mock-chaturbate.html   локальная копия чата Chaturbate
  mock-whatsapp.html     локальная копия WhatsApp Web
  e2e.mjs                автотест в Chromium
```

Новый сайт = новый файл в `content/adapters/` с теми же функциями (`match`, `findMessages`, `shouldSkip`, `extract`, `findInput`) + адрес сайта и файл в `manifest.json`.

Расширение только читает страницу в браузере пользователя: никаких закрытых API сайтов и обхода защиты.

## Тесты

```
npm install
npx playwright install chromium
npm test
```

Тест открывает `test/mock-chaturbate.html` с расширением (провайдер «Проверка», без интернета) и проверяет перевод входящих, вставку ответа (в contenteditable и в textarea), выключение и кэш.

Тестовую страницу можно открыть и вручную: запусти в корне репозитория `npx http-server test -p 8080` (или `python -m http.server 8080 -d test`) и открой `http://localhost:8080/mock-chaturbate.html`.
